# Dataset status and join keys

## WP4 evidence-gated draft

`data/processed/hri/wp4_v1/species_vulnerability_index.csv` has one row per accepted endemic species (24). The accompanying evidence table has one species × indicator row (144); sensitivity has one species × weight scenario row (144,048). The manifest records input hashes. **Composite scores and ranks are unavailable because evidence coverage is insufficient.** Available ordinal component scores are not a complete SVI and must not be used as priority weights. See [methodology](docs/methodology/species_vulnerability_methodology.md); reproduce with `python3 scripts/build_species_vulnerability.py` from the component directory.

## Current WP2 occurrence release

Use [wp2_v1 release report](data/processed/hri/wp2_v1/README.md) for the accepted occurrence eligibility rules and limitations. The versioned release has 101,535 eligible rows, 24 recorded endemic species, 3,713 observed cell-years and 16,151 unique cell-year-species combinations. It retains 1,394 excluded/withheld rows in a separate table and all 102,929 source rows in its decision ledger. Source IDs are scoped to the input checksum.

Notebook Cells 51–56 reproduce this reconciliation with visible code. The older root-level processed files and interim review templates below are historical preparation outputs, not the current release. Species scope acceptance does not complete vulnerability-trait verification. Boundary exceptions are withheld without invented coordinate corrections. HRI/priority/model readiness is not implied.

Release tables use the row units below: observations and decision ledger are source records; scope is one original species; location verification is one coordinate pair; species evidence is cell × reference year × accepted scientific name; sampling is observed cell × reference year; sensitivity is one scenario. Missing sampling rows do not establish bird absence.

| Table | Row unit / join key | Status |
|---|---|---|
| Original observation CSV | Observation record; no verified checklist key | Immutable source |
| Bird cleaning draft | Source record, with source_row_id when generated by integrated notebook | Review flags retained |
| Endemic candidates | Observation record | Endemic scope does not resolve all record/trait quality |
| HRI cell-year preparation | cell_id + reference_year | Combined environmental evidence; coverage flags retained |
| HRI cell-year species evidence | cell_id + reference_year + scientific_name | Dated occurrence summaries; trait snapshots are not historical predictors |
| Endemic mapping review | Observation record | Unmatched mapping/date cases; not discarded |
| species_traits.csv | scientific_name | Partially verified; no vulnerability weights |
| Grid summaries | cell_id | Provisional spatial scale |
| Weather summaries | cell_id + reference_year | Verified source, with spatial coverage limits |
| Terrain summaries | cell_id | Coverage and surface-height limitations |

Do not call the merged preparation tables the final cleaned HRI training dataset. Existing record flags, excluded/poor coverage and unresolved traits require decisions. Missing bird observations do not establish absence or low risk. HRI scores/classes are not present. All relevant file names were kept to preserve notebook references.
